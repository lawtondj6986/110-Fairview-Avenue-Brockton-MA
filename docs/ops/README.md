## Before the first paid engagement (do these once)
1. **Attorney review** of the engagement letter + the private-investigator licensing question (M.G.L. c. 147).
2. **Bind insurance** — professional/media-liability (E&O).
3. **Stand up the Conflict Registry** (Appendix B of the SOP) and keep it current — it's the exclusivity promise.
4. Paste the **Formspree key** into `SITE.formEndpoint` so the intake forms capture leads instead of composing email.

Keep it boring and repeatable. The discipline is the product.
