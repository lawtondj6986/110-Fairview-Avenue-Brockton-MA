## Part 4 — Price

**Quote = Floor + (Score ÷ 14) × (Ceiling − Floor)**, rounded to the nearest $250.

- Floor $[____] + ( [score] ÷ 14 ) × ( Ceiling $[____] − Floor $[____] ) = **$[____]**

**Expenses** (billed at cost or bundled): court/record retrieval $[____] · database/archive $[____].
**Deposit:** 50% on signing = **$[____]**   ·   **Balance:** on delivery = **$[____]**
*(Rapid-Response: $[____]/month, first month on signing.)*

### Worked example
Opposition Book (floor $7,500 / ceiling $15,000). Subject: 12-yr select board member, 2 counties, 3 LLCs,
1 subject, some litigation, multi-source depth, 2-week turnaround → scores 1+1+1+0+1+1+1 = **6/14**.
Quote = 7,500 + (6 ÷ 14) × 7,500 = 7,500 + 3,214 = **$10,750** → rounded **$10,750**. Deposit $5,375.
