A genotyping array is a small chip that tests a DNA sample at a fixed list of positions already
known to vary between people. A typical array checks from several hundred thousand to a few million
positions, mostly single nucleotide polymorphisms. For each position it reports which versions the
person carries.

Arrays are fast and inexpensive, which is why most consumer ancestry and trait tests use them and
why large research studies have genotyped very many participants. Statistical methods can then
estimate, or "impute", some positions that the array did not test directly, using patterns seen in
reference populations.

An array is not sequencing. It reads far less than one percent of the genome and cannot detect a
variant that was not included in its design. It is best at common variants and less reliable for
rare ones, where false positives are a recognized problem. For that reason a medically important
result from an array is normally confirmed by a clinical laboratory using a different method before
anyone acts on it. A raw data file downloaded from a consumer test is array data and carries the
same limits.
